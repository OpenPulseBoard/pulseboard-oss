PulseBoard Cloud docs

This standalone cloud build serves the hosted control-plane surface. Workspace product docs still live with the OSS workspace runtime.

What lives here

  • Customer auth under /api/auth/*
  • Portal APIs under /api/portal/*
  • Provisioner-facing signup flow on the apex host

What does not live here

Ingest, query, dashboards, alerts, retention, and the operator UI stay on each workspace runtime. Those are part of the OSS product surface.
